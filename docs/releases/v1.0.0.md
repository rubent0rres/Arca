# Arca 1.0.0

Primera versión de Arca, el gestor de archivos comprimidos para macOS desarrollado por **Rubén J. Torres**.

## Funciones incluidas

- Explorar, extraer, comprobar y crear archivos RAR, 7z y ZIP.
- Abrir archivos con arrastrar y soltar o seleccionarlos en Finder.
- Navegar por las carpetas del archivo y buscar contenido por nombre o ruta.
- Detectar archivos protegidos y recordar la contraseña solo mientras el archivo permanece abierto.
- Mostrar progreso de extracción y resultados en una barra de estado permanente.
- Consultar información del archivo y datos del desarrollador en sus respectivos modales.
- Interfaz oscura e icono de Arca integrado en macOS.

## Descargar e instalar

**[Descargar Arca 1.0.0 para macOS · Apple Silicon (arm64)](https://github.com/rubent0rres/Arca/releases/download/v1.0.0/Arca-1.0.0-macOS-arm64.dmg)**

Abre el DMG, arrastra **Arca** a **Aplicaciones**, expulsa la imagen de disco y abre la app desde Aplicaciones.

El instalador incluye 7-Zip para los formatos 7z y ZIP. RAR y UnRAR deben instalarse por separado para las operaciones con archivos RAR; consulta las [instrucciones del README](https://github.com/rubent0rres/Arca/tree/v1.0.0#herramientas-rar).

Esta versión es para Apple Silicon; no incluye un instalador para Mac Intel. La creación admite archivos individuales, no carpetas, y no ofrece creación con contraseña.

La aplicación tiene una firma local (ad hoc) y no está notarizada por Apple. Para incidencias en la primera apertura, consulta la [guía oficial de Apple](https://support.apple.com/es-mx/102445).

## Integridad de la descarga

El archivo [SHA256SUMS.txt](https://github.com/rubent0rres/Arca/releases/download/v1.0.0/SHA256SUMS.txt) contiene la suma SHA-256 del instalador.
